# Optional bundled fonts

Place redistributable TTF, OTF, TTC, or OTC files here when the node pack should ship them.

Every bundled font must include its license text and attribution. Do not copy system fonts into this directory unless their license explicitly permits redistribution. `Labeled Image Collage Ψ` also supports an explicit local `font_path` and automatically checks the Git-ignored `incoming/` and legacy `temp/` directories during development.
