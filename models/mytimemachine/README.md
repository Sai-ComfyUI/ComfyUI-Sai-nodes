# MyTimeMachine model files

Place downloaded weights in this directory. The loader scans subdirectories,
and known training-only files are hidden from its inference checkpoint menus.

Model weights are ignored by Git and must not be committed. See
[`docs/MODELS.md`](../../docs/MODELS.md) for the exact inference, alignment, and
training file sets; original model sources are listed first and the maintained
Hugging Face mirror is provided as a secondary source.
